Seating App - Quick Start Guide

Quick Start

  • Import: Click “Import Class List” and choose an Excel (.xls/.xlsx) classlist (download from PYCnet) or a previously exported seat_readable.txt. The app auto-detects classes and builds class buttons.
  • Choose class: Click a class button (turns green) to set the active class.
  • Assignment: Pick Random (shuffle) or Sequential (by number; direction depends on door setting).
  • Generate: Click “Generate Seating.” Drag seats to rearrange. Drop onto gray seats to move, or into “Unused Students” to store temporarily. Drag back to place.
  • Advanced: Use “Add New Column” (left/right) or “Advanced” (custom title, rows/columns, 1–2 doors).
  • Export: Download PNG/JPG (image), PDF (document), or TXT (re-importable layout).

Q & A

Which file formats are supported?

Excel with header “pyccode” and either “Class/No.” or “Class No.”; or seat_readable.txt from a prior export.

In case you don't know how to get the supported Excel document：

1. Login PYCnet, go to "Manage my group" of "Messages".

2. Select "Create new group" or an existing class group.

3. Select the students you want to be in the group.

4. Select "Save as Excel file".

Then you should obtain a supported Excel document.

What do Random and Sequential do?

Random shuffles; Sequential sorts by student number and fills by columns from the door side.

How do doors affect seating?

1 door fills from left; 2 doors set fills from right and shows front/back door labels.

How to create aisles or gaps?

Add a left/right column or set custom columns, then leave cells empty (gray, non-draggable).

How do exports differ?

PNG/JPG for sharing; PDF for printing/archiving; TXT to fully restore the layout later.

Drag-and-drop tips?

Drag colored/white seats; targets highlight on hover; storage strip accepts drops; gray seats are fixed placeholders.
